## ១. សេចក្ដីផ្ដើមអំពីប្រព័ន្ធ (System Overview)

**ប្រព័ន្ធគ្រប់គ្រងស្តុកទំនិញ (Enterprise Inventory Management System)** គឺជាកម្មវិធី Desktop លំដាប់សហគ្រាស (Enterprise-grade) ត្រូវបានរៀបចំឡើងជាពិសេសសម្រាប់អាជីវកម្មលក់រាយ (Retail) លក់ដុំ (Wholesale) ម៉ាត ឃ្លាំងស្តុក និងសហគ្រាសធុនតូច និងមធ្យម (SMEs)។

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងដោយប្រើប្រាស់បច្ចេកវិទ្យាទំនើប **C# 13, .NET 9.0 (Windows Forms)** រួមជាមួយ **Microsoft SQL Server**, **LiveCharts v2**, និង **Telegram Bot API** ដោយអនុវត្តតាមស្ថាបត្យកម្ម **3-Tier Architecture** និងគោលការណ៍ **OOAD (Object-Oriented Analysis & Design)**។

## ២. បញ្ហាប្រឈមក្នុងអាជីវកម្ម និងដំណោះស្រាយ (Business Challenges & Solutions)

នៅក្នុងការគ្រប់គ្រងអាជីវកម្មបែបបុរាណ ម្ចាស់អាជីវកម្មតែងតែជួបប្រទះនូវបញ្ហាធំៗជាច្រើន៖

| បញ្ហាប្រឈមបែបបុរាណ (Manual / Excel) | ផលប៉ះពាល់ដល់អាជីវកម្ម | ដំណោះស្រាយរបស់ប្រព័ន្ធយើង |
| :--- | :--- | :--- |
| **កត់ត្រាក្នុងសៀវភៅ ឬ Excel** | ងាយភ្លេច ងាយបាត់ទិន្នន័យ គ្មានភាពសុក្រឹត | ប្រព័ន្ធ Database កណ្ដាល (SQL Server) ផ្ទុកទិន្នន័យមានសុវត្ថិភាព ១០០% |
| **ការលក់លើសចំនួនស្តុក (Overselling)** | អតិថិជនកុម្ម៉ង់រួច តែគ្មានទំនិញប្រគល់ឱ្យ បាត់បង់ទំនុកចិត្ត | ច្បាប់ **Zero-Deficit**: ប្រព័ន្ធហាមឃាត់ដាច់ខាតមិនឱ្យស្តុកធ្លាក់ក្រោមសូន្យ |
| **មិនដឹងពេលណាទំនិញជិតអស់** | ទាល់តែដាច់ស្តុកទើបដឹង បាត់បង់ឱកាសលក់ | ជូនដំណឹងស្វ័យប្រវត្តិតាម **Telegram Bot** ទៅទូរស័ព្ទដៃភ្លាមៗ |
| **ច្រឡំមុខទំនិញពេលលើកចេញ (Picking Error)** | ឈ្មោះស្រដៀងគ្នាប៉ុន្តែម៉ូដែលខុសគ្នា លើកខុសឱ្យម៉ូយ | ផ្ទាំង **Visual Verification Card** បង្ហាញរូបភាព និងព័ត៌មានទំនិញពេលស្កេន |
| **បុគ្គលិកដឹងថ្លៃដើម និងប្រាក់ចំណេញ** | បែកធ្លាយទិន្នន័យសម្ងាត់អាជីវកម្ម | ការពារដោយ **RBAC**: លាក់ថ្លៃដើមពី Staff និង Sales ដោយស្វ័យប្រវត្តិ |
| **ពិបាកចេញវិក្កយបត្រឱ្យម៉ូយ** | ត្រូវសរសេរដៃ យឺតយ៉ាវ និងមិនមានវិជ្ជាជីវៈ | ចេញ **Invoice / Receipt** ស្អាតកម្រិត High-DPI និង Export ជា PDF ភ្លាមៗ |

## ៣. អត្ថប្រយោជន៍ចម្បងៗដែលជួយដល់អាជីវកម្ម (Key Business Benefits)

### ១. ភាពសុក្រឹតនៃស្តុក ១០០% (Zero Deficit & Invariant Control)
- ប្រព័ន្ធមិនអនុញ្ញាតឱ្យលក់ទំនិញដែលគ្មាននៅក្នុងស្តុកឡើយ (`CurrentStock >= Quantity`)។
- ការពារការកេងបន្លំ ឬការបាត់បង់ទំនិញដោយមិនដឹងមូលហេតុ។

### ២. ដឹងដំណឹងទាន់ហេតុការណ៍លើទូរស័ព្ទដៃ (24/7 Real-Time Telegram Alerts)
- រាល់ពេលបុគ្គលិកលក់ទំនិញរហូតដល់កម្រិតកំណត់ (Reorder Level) ឬអស់ពីស្តុក ប្រព័ន្ធនឹងបាញ់សារជាភាសាខ្មែរទៅកាន់ **Telegram Bot** ភ្លាមៗ។
- ម្ចាស់អាជីវកម្មមិនចាំបាច់អង្គុយចាំមើលកុំព្យូទ័រ ក៏ដឹងថាទំនិញណាត្រូវកម្ម៉ង់បន្ថែមដែរ។

### ៣. បង្កើនល្បឿន និងប្រសិទ្ធភាពការងារ (High Operational Speed)
- គាំទ្រការស្កេនបាកូដរហ័ស (Barcode / SKU Instant Scanner) ដោយគ្រាន់តែចុចម៉ាស៊ីនស្កេន ប្រព័ន្ធនឹងទាញយកទំនិញភ្លាមក្នុងរយៈពេល ០.១ វិនាទី។
- កាត់បន្ថយពេលវេលារាប់ស្តុក និងចេញទំនិញបានលើសពី ៧០%។

### ៤. កាត់បន្ថយការច្រឡំទំនិញ (Visual Warehouse Picking Card)
- ពេលជ្រើសរើសទំនិញ ប្រព័ន្ធនឹងបង្ហាញរូបភាពពិត ទំហំ ម៉ាក និងចំនួននៅសល់ក្នុងស្តុក។ បុគ្គលិកឃ្លាំងអាចផ្ទៀងផ្ទាត់រូបភាពមុននឹងប្រគល់ទំនិញទៅឱ្យអតិថិជន។

### ៥. ការគ្រប់គ្រងលំហូរសាច់ប្រាក់ និងទ្រព្យសកម្មច្បាស់លាស់ (Capital Valuation & Analytics)
- ផ្ទាំង Dashboard បង្ហាញតម្លៃសរុបនៃទំនិញក្នុងស្តុក (Asset Valuation) គិតជាសាច់ប្រាក់ជាក់ស្ដែង។
- ក្រាហ្វិក LiveCharts បង្ហាញពីសមាមាត្រទំនិញនាំចូលធៀបនឹងនាំចេញក្នុងរយៈពេល ៦ ខែ និងការបែងចែកទុនតាមប្រភេទផលិតផល។

### ៦. លើកកម្ពស់មុខមាត់អាជីវកម្ម (Professional Invoicing)
- មានប្រព័ន្ធបោះពុម្ពវិក្កយបត្រ GDI+ ទំនើប បង្ហាញឡូហ្គោហាង (`logo.png`) កាលបរិច្ឆេទ លេខវិក្កយបត្រ តារាងទំនិញ និងហត្ថលេខា អាចបោះពុម្ពចេញលើក្រដាស A4 ឬក្រដាសកម្ដៅ (Thermal Receipt) និង Save ជា PDF បានភ្លាមៗ។

## ៤. ការបែងចែកតួនាទី និងសិទ្ធិប្រើប្រាស់ (Role-Based Access Control - RBAC)

ប្រព័ន្ធបានកំណត់សិទ្ធិប្រើប្រាស់យ៉ាងច្បាស់លាស់ដើម្បីធានាសុវត្ថិភាព និងការសម្ងាត់ក្នុងស្ថាប័ន៖

| តួនាទី (Role) | គណនីគំរូ | ពាក្យសម្ងាត់ | សិទ្ធិ និងដែនកំណត់ក្នុងប្រព័ន្ធ |
| :--- | :--- | :--- | :--- |
| **Administrator** (ម្ចាស់អាជីវកម្ម / អ្នកគ្រប់គ្រងទូទៅ) | `admin` | `123` | **សិទ្ធិពេញលេញ (Full Access):** មើលរបាយការណ៍ហិរញ្ញវត្ថុ, មើលថ្លៃដើម និងប្រាក់ចំណេញ, បន្ថែម/កែប្រែ/លុបទំនិញ, គ្រប់គ្រង Category, កំណត់ Telegram Bot, និងកែប្រែ Settings។ |

## ៥. ការណែនាំពីរបៀបប្រើប្រាស់ជាជំហានៗ (Step-by-Step User Guide)

### ជំហានទី ១៖ ការចូលប្រើប្រាស់ប្រព័ន្ធ (Login & Authentication)
1. បើកកម្មវិធី នោះផ្ទាំង **Account Authentication** នឹងបង្ហាញឡើង។
2. វាយបញ្ចូល **Username** (`admin`, `staff`, ឬ `sales`) និង **Password** (`123`)។
3. អាចចុចលើរូបភ្នែក (**👁️**) ដើម្បីមើលលេខសម្ងាត់។
4. គូសធីកលើ **Remember Me for 7 Days** ប្រសិនបើចង់ឱ្យប្រព័ន្ធចងចាំការ Login រយៈពេល ៧ ថ្ងៃ (លើកក្រោយបើកមកចូល Dashboard ផ្ទាល់តែម្ដង)។
5. ចុចប៊ូតុង **Sign In ➔** ដើម្បីចូលប្រើប្រាស់។

### ជំហានទី ២៖ ផ្ទាំងគ្រប់គ្រងទិន្នន័យទូទៅ (Executive Dashboard)
បន្ទាប់ពី Login រួច អ្នកនឹងឃើញផ្ទាំង **Executive Dashboard** ដែលមានព័ត៌មានសំខាន់ៗចំនួន ៤ ផ្នែក៖
1. **កាតសង្ខេប KPIs ចំនួន ៤៖**
   - **Total Inventory:** ចំនួនទំនិញសរុបទាំងអស់ក្នុងឃ្លាំង និងចំនួនមុខទំនិញ (SKUs)។
   - **Asset Valuation:** តម្លៃសរុបជាទឹកប្រាក់នៃទំនិញក្នុងស្តុកទាំងអស់។
   - **Restock Alerts:** ចំនួនមុខទំនិញដែលកំពុងធ្លាក់ចុះដល់កម្រិតជិតអស់ ឬអស់ពីស្តុក។
   - **Today's Movement:** ចំនួនចលនាទំនិញចូល និងចេញប្រចាំថ្ងៃ។
2. **ក្រាហ្វិកវិភាគ (LiveCharts Analytics):**
   - ក្រាហ្វិកជួរឈរប្រៀបធៀបការនាំចូល (Inflow) និងនាំចេញ (Outflow) ក្នុងរយៈពេល ៦ ខែកន្លងមក។
   - ក្រាហ្វិករង្វង់ (Donut Chart) បង្ហាញពីភាគរយនៃទុនវិនិយោគតាមប្រភេទទំនិញនីមួយៗ (Category Valuation)។
3. **តារាងតាមដានទំនិញជិតអស់បន្ទាន់ (Urgent Restock Deficit Monitor):**
   - បង្ហាញទំនិញដែលមានពណ៌លឿង (ជិតអស់) និងពណ៌ក្រហម (អស់ពីស្តុក)។
   - អាច Double-click លើជួរទំនិញណាមួយដើម្បីបើកផ្ទាំង Restock បន្ថែមស្តុកបានភ្លាមៗ។
4. **ប៊ូតុងផ្ញើ Alert ទៅ Telegram (📲 ផ្ញើ Alert ទៅ Telegram):**
   - ចុចដើម្បីបាញ់របាយការណ៍ទំនិញជិតអស់ទាំងអស់ចូលទៅក្នុង Telegram Bot ភ្លាមៗដោយស្វ័យប្រវត្តិ។

### ជំហានទី ៣៖ ការគ្រប់គ្រងទំនិញ និងប្រភេទទំនិញ (Products & Categories Management)

#### ក. ការបន្ថែមទំនិញថ្មី (Add New Product)
1. ចុចលើម៉ឺនុយ **`📦 Product Catalog`** នៅរបារខាងឆ្វេង។
2. ចុចប៊ូតុង **`+ Add Product`** នៅជ្រុងខាងស្ដាំខាងលើ។
3. បំពេញព័ត៌មានទំនិញ៖
   - **SKU Code\***: លេខកូដសម្គាល់ទំនិញ (ឧទាហរណ៍៖ `TECH-LAP-001`)។
   - **Barcode / UPC**: លេខកូដបាកូដលើប្រអប់ទំនិញ (អាចប្រើម៉ាស៊ីនស្កេនបាញ់បញ្ចូល)។
   - **Product Name\***: ឈ្មោះទំនិញពេញលេញ។
   - **Category\***: ជ្រើសរើសប្រភេទទំនិញ (ឧ. Electronics, Perishables...)។
   - **Supplier\***: ជ្រើសរើសក្រុមហ៊ុនផ្គត់ផ្គង់។
   - **Cost Price ($)\***: ថ្លៃដើមទិញចូល។
   - **Selling Price ($)\***: តម្លៃលក់ចេញ (ប្រព័ន្ធនឹងគណនា % ប្រាក់ចំណេញ Profit Margin បង្ហាញភ្លាមៗ)។
   - **Initial Stock**: ចំនួនស្តុកដំបូង។
   - **Reorder Level**: កម្រិតព្រមានពេលជិតអស់ស្តុក (ឧ. នៅសល់ត្រឹម ១០ គ្រាប់ឱ្យប្រព័ន្ធ Alert)។
4. **បញ្ចូលរូបភាពទំនិញ (Upload Product Image):**
   - នៅផ្ទាំងខាងស្ដាំ ចុចប៊ូតុង **`📁 Browse Image...`** រួចជ្រើសរើសរូបភាព (`.png`, `.jpg`, `.webp`)។
   - រូបភាពនឹងត្រូវបញ្ចូលក្នុងប្រព័ន្ធដោយសុវត្ថិភាព។
5. ចុចប៊ូតុង **`💾 Save Product`** ដើម្បីរក្សាទុក។

#### ខ. ការគ្រប់គ្រង Category
- អាចបន្ថែម កែប្រែ ឬលុប Category បានយ៉ាងងាយស្រួល។
- ប្រព័ន្ធមានប្រព័ន្ធសុវត្ថិភាពការពារមិនឱ្យលុប Category ណាដែលមានទំនិញកំពុងប្រើប្រាស់ឡើយ។

### ជំហានទី ៤៖ ការនាំចូល នាំចេញ និងស្កេនបាកូដ (Stock In / Out & Barcode Scanner)

នៅពេលមានការនាំទំនិញចូលឃ្លាំង ឬលក់ទំនិញចេញឱ្យម៉ូយ សូមចុចលើ **`+ Record Stock Movement`** ឬប៊ូតុង **`Quick Restock`**៖

1. **ស្កេនបាកូដរហ័ស (⚡ Quick Barcode / SKU Scanner):**
   - ដាក់ Cursor ក្នុងប្រអប់ស្កេន រួចបាញ់ម៉ាស៊ីនស្កេនបាកូដលើទំនិញ។
   - ប្រព័ន្ធនឹងស្វែងរក និងជ្រើសរើសទំនិញនោះដោយស្វ័យប្រវត្តិក្នងពេលត្រឹមតែ ០.១ វិនាទី។
2. **ផ្ទៀងផ្ទាត់រូបភាព (Visual Verification Card):**
   - ផ្ទាំងខាងស្ដាំនឹងបង្ហាញរូបភាពពិត ឈ្មោះ កូដ SKU និងចំនួនស្តុកបច្ចុប្បន្ន ដើម្បីឱ្យបុគ្គលិកផ្ទៀងផ្ទាត់កុំឱ្យច្រឡំទំនិញ។
3. **ជ្រើសរើសប្រភេទចលនាស្តុក (Movement Type):**
   - **`IN (Restock)`**: សម្រាប់ទំនិញនាំចូលពីអ្នកផ្គត់ផ្គង់ (បន្ថែមចំនួនស្តុក)។
   - **`OUT (Sale / Dispatch)`**: សម្រាប់លក់ចេញ ឬបញ្ជូនទៅអតិថិជន (កាត់បន្ថយស្តុក)។
   - **`ADJUSTMENT (Audit Count)`**: សម្រាប់កែតម្រូវចំនួនស្តុកជាក់ស្ដែងពេលធ្វើសវនកម្មរាប់ឃ្លាំង។
4. **មើលការប្រែប្រួលស្តុកជាមុន (Live Stock Impact Preview):**
   - នៅខាងក្រោម ប្រព័ន្ធនឹងបង្ហាញ៖ `Stock Preview: 25 -> 50 (+25 units)`។
   - បើសិនជាចំនួនលក់ចេញលើសពីស្តុក ប្រព័ន្ធនឹងចេញពណ៌ក្រហមព្រមានភ្លាមៗ៖ `Insufficient Stock!`។
5. ចុច **`Confirm & Record Movement`** ដើម្បីកត់ត្រាចូលទៅក្នុង Database ដោយសុវត្ថិភាព។

### ជំហានទី ៥៖ ការចេញវិក្កយបត្រ និងបោះពុម្ពបង្កាន់ដៃ (Printable Invoices & Receipts)

បន្ទាប់ពីកត់ត្រាការលក់ទំនិញចេញរួច ប្រព័ន្ធនឹងសួរថា៖  
*«តើអ្នកចង់ Preview និងបោះពុម្ពវិក្កយបត្រ/បង្កាន់ដៃឥឡូវនេះដែរឬទេ?»*

1. ចុច **`Yes`** ដើម្បីបើកផ្ទាំង **Invoice Preview Viewer**។
2. **លក្ខណៈពិសេសនៃវិក្កយបត្រ៖**
   - បង្ហាញឡូហ្គោក្រុមហ៊ុន (`logo.png`) និងបូរពណ៌លឿងរចនាបថទំនើប (Modern Yellow Header Band)។
   - មានលេខវិក្កយបត្រ (Invoice #), កាលបរិច្ឆេទ, និងឈ្មោះអតិថិជន។
   - តារាងទំនិញច្បាស់លាស់ (ល.រ, ឈ្មោះទំនិញ, តម្លៃឯកតា, ចំនួន, និងទឹកប្រាក់សរុប)។
   - ប្រអប់សរុបប្រាក់ពណ៌លឿងច្បាស់ៗ (Sub Total, Tax, និង Grand Total)។
   - កន្លែងចុះហត្ថលេខារបស់អ្នកលក់ និងលក្ខខណ្ឌទូទាត់។
3. **ជម្រើសនៃការបោះពុម្ព៖**
   - **🖨️ Print Invoice...**: ជ្រើសរើសម៉ាស៊ីនព្រីន (Printer) ណាមួយក៏បាន។
   - **📄 Quick PDF / Direct Print**: ចុចតែ ១ Click ដើម្បី Save ជា file PDF។
   - **🔍 Zoom In / Out**: ពង្រីកមើលព័ត៌មានលម្អិតបានរហូតដល់ ២៥០%។

### ជំហានទី ៦៖ ប្រព័ន្ធជូនដំណឹងតាម Telegram Bot (Real-time Telegram Alerts)

ប្រព័ន្ធភ្ជាប់មកជាមួយសេវាកម្ម **Telegram Bot API** ដែលបង្កើតឡើងជាពិសេសសម្រាប់ផ្តល់ភាពងាយស្រួលដល់ម្ចាស់អាជីវកម្ម៖

1. **ដំណើរការដោយស្វ័យប្រវត្តិ (Automated Notifications):**
   - រាល់ពេលស្តុកទំនិញធ្លាក់ចុះដល់កម្រិតកំណត់ (Reorder Level) សារ Alert ជាភាសាខ្មែរនឹងលោតចូលទៅ Telegram ភ្លាមៗ ឧទាហរណ៍៖  
     *`⚠️ ការជូនដំណឹង៖ ទំនិញ [Dell Laptop] នៅសល់ត្រឹម ៣ គ្រឿង (ជិតអស់ពីស្តុក)!`*
   - ប្រសិនបើតម្លៃស្តុកស្មើ ០ សារនឹងប្រាប់ថា៖  
     *`🚨 អាសន្ន៖ ទំនិញ [Coca Cola] អស់ពីស្តុកហើយ! សូមកម្ម៉ង់បន្ថែមជាបន្ទាន់។`*
2. **ការកំណត់ងាយស្រួលក្នុង System Settings:**
   - គ្រាន់តែបញ្ចូល **Bot Token** និង **Chat ID**។
   - មានមុខងារ **Detect Latest Chat ID** ដោយគ្រាន់តែចូលទៅ Chat ជាមួយ Bot រួចចុចប៊ូតុង នោះប្រព័ន្ធនឹងរក Chat ID ដោយស្វ័យប្រវត្តិ។
   - មានប៊ូតុង **Send Test Message** ដើម្បីតេស្តសាកល្បងផ្ញើសារជាភាសាខ្មែរ។

---

### ជំហានទី ៧៖ ការធ្វើសវនកម្ម និងតាមដានតម្លៃស្តុក (Inventory Audits & Valuation)

ចុចលើម៉ឺនុយ **`📑 Inventory Audits`** ដើម្បីត្រួតពិនិត្យសុខភាពស្តុកទូទៅ៖
- **Catalog Valuation:** បង្ហាញតម្លៃសរុបនៃទុនទាំងអស់ដែលកំពុងកកស្ទះនៅក្នុងឃ្លាំង។
- **Automated Audit Verdicts:** ប្រព័ន្ធនឹងវិភាគទំនិញទាំងអស់ជាស្វ័យប្រវត្តិ៖
  * `OPTIMAL - Stock Invariants Satisfied`: ស្តុកមានតុល្យភាពល្អ។
  * `WARNING - Approaching Reorder Point`: ស្តុកចាប់ផ្ដើមខ្វះ ត្រូវត្រៀមបញ្ជាទិញ។
  * `DEFICIT - Immediate Restock Needed`: ស្តុកអស់ទាំងស្រុង។
- **Physical Audit Scan:** អាចចុច **`Run Physical Audit Verification`** ដើម្បីផ្ទៀងផ្ទាត់តុល្យភាពទិន្នន័យក្នុងប្រព័ន្ធឡើងវិញ។

---

## ៦. ចំណុចខ្លាំងផ្នែកបច្ចេកវិទ្យា និងសុវត្ថិភាព (Technical Highlights)

1. **ស្ថាបត្យកម្ម 3-Tier Enterprise Architecture:**
   - បំបែកការងារដាច់ពីគ្នា៖ Presentation Layer (UI), Business Logic Layer (BLL), និង Data Access Layer (DAL) ដែលធ្វើឱ្យកម្មវិធីរលូន ងាយស្រួលថែទាំ និងមានស្ថិរភាពខ្ពស់។
2. **ACID Transaction & UPDLOCK Concurrency Control:**
   - ការកត់ត្រាចលនាស្តុកប្រើប្រាស់ `SqlTransaction` ជាមួយ `UPDLOCK` ដែលការពារដាច់ខាតមិនឱ្យទិន្នន័យជាន់គ្នា (Race Conditions) ទោះបីជាមានបុគ្គលិកច្រើននាក់លក់ទំនិញដំណាលគ្នាក៏ដោយ។
3. **Resilient Academic Demo Mode:**
   - ប្រសិនបើ SQL Server ត្រូវបានបិទ ឬជួបបញ្ហាតភ្ជាប់ កម្មវិធី **មិនរលត់ (Not Crash)** ឡើយ ដោយប្រព័ន្ធនឹងប្ដូរទៅប្រើប្រាស់ Demo Mode ដោយស្វ័យប្រវត្តិដើម្បីឱ្យអ្នកប្រើប្រាស់នៅតែអាចពិនិត្យមើល UI បាន។
4. **រូបភាពទំនិញ Non-Locking Memory Stream:**
   - រាល់រូបភាពទំនិញត្រូវបានផ្ទុកតាមរយៈ Memory Stream ដូច្នេះកម្មវិធីមិនជាប់ Lock File លើ Hard Drive ឡើយ ដែលអនុញ្ញាតឱ្យកែប្រែ ឬលុបរូបភាពបានគ្រប់ពេលវេលា។

## ៧. សេចក្ដីសន្និដ្ឋាន (Conclusion)

**ប្រព័ន្ធគ្រប់គ្រងស្តុកទំនិញ (Inventory Management System)** មិនត្រឹមតែជាកម្មវិធីសម្រាប់កត់ត្រាទិន្នន័យប៉ុណ្ណោះទេ ប៉ុន្តែជា **ដំណោះស្រាយយុទ្ធសាស្ត្រ** ជួយឱ្យអាជីវកម្ម៖
- ✅ លុបបំបាត់ការបាត់បង់ស្តុក និងកាត់បន្ថយកំហុសមនុស្ស (Human Errors) ដល់ទៅ ០%
- ✅ ដឹងព័ត៌មានស្តុក ២៤ ម៉ោងលើ ២៤ ម៉ោងតាមរយៈ Telegram Bot លើទូរស័ព្ទដៃ
- ✅ បង្កើនល្បឿននៃការលក់ និងការចេញទំនិញជាមួយម៉ាស៊ីនស្កេនបាកូដ
- ✅ មានវិក្កយបត្រស្អាត ប្រកបដោយវិជ្ជាជីវៈខ្ពស់
- ✅ ជួយឱ្យម្ចាស់អាជីវកម្មគ្រប់គ្រងលំហូរទុន និងប្រាក់ចំណេញបានយ៉ាងជាក់ច្បាស់ និងទាន់ពេលវេលា។
