## 🚀 Quick Start
1. **Initialize Database**: Execute [`Database/InventoryDB_Setup.sql`](file:///c:/Users/Panha/source/repos/Inventory%20Management%20System/Inventory%20Management%20System/Database/InventoryDB_Setup.sql) in SQL Server Management Studio.
2. **Configure Connection**: Verify connection string in [`App.config`](file:///c:/Users/Panha/source/repos/Inventory%20Management%20System/Inventory%20Management%20System/App.config).
3. **Run Application**:
   ```powershell
   dotnet build
   dotnet run
   ```
4. **Log In**:
   - **Admin**: Username: `admin` | Password: `123`
   - **Staff**: Username: `staff` | Password: `123`
   - **Sales Staff**: Username: `sales` | Password: `123`
